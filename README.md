# brainblocks
STL files for custom 3-D printed brain slicers/matrixes/blocks

Will be making an improved version using 3D MRI models in the future! Please let me know if you have any suggestions for improvements!

### **Adult Rat Brain Slicer Version 1 (March 2020)**
*https://3d.nih.gov/entries/3DPX-020477*
![Fig_3_custom_brain_slicer_for_conference](https://github.com/user-attachments/assets/c593e5f4-5b6f-43c5-8c6a-1b1fe9853f82)
*3-D Printed with Veroclear using the Stratasys J750 3-D polyjet printer ([more info](https://3d.nih.gov/builds/470))*

This model of a 3-D printed brain slicer for adult rat brains produces coronal sections approximately 800μm thick. Each divider is 0.5mm, and the slots are 0.3mm (fitting double-edge razor blades with a thickness of 0.1mm). 
* Left - (38.5mm L × 18mm W × 12.5mm H)
* Right - (38.5mm L × 18mm W × 15mm H)

The design is adapted from Darrell Hurt’s 3-D brain slicer [3DPX-000286](https://3d.nih.gov/entries/3DPX-000286) and recreated with modifications in [Tinkercad](https://www.tinkercad.com/things/2iAVdrWJJRK).
